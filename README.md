# goit-rdb-hw-04
При використанні INNER JOIN у результат потрапляють лише ті рядки, для яких існують відповідні записи у всіх об'єднаних таблицях. Якщо хоча б в одній таблиці немає відповідного значення — такий рядок виключається.

При заміні INNER JOIN на LEFT JOIN кількість рядків зазвичай збільшується або залишається такою ж. Це відбувається тому, що LEFT JOIN повертає всі рядки з лівої таблиці (order_details), навіть якщо для них немає відповідних записів у пов’язаних таблицях. У таких випадках значення з інших таблиць будуть NULL.

Таким чином:

INNER JOIN → залишає тільки повністю пов’язані дані → менше рядків
LEFT JOIN → додає також непов’язані записи → більше або стільки ж рядків

Причина зміни кількості рядків полягає у різній логіці об’єднання даних: INNER JOIN фільтрує, а LEFT JOIN — зберігає всі записи з основної таблиці.
